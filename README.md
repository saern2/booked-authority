# Booked Authority — Landing Page

Live, verified landing page for Booked Authority, the ebook creation service.

## What is in this folder

- `index.html` — the complete page, self-contained. All 12 book covers and all 4 Whom We Work With logos are inlined, so no other files are needed.
- `vercel.json` — Vercel static settings only. No build step, no framework, no environment variables.

## Deploy in 5 minutes: GitHub to Vercel

1. Go to https://github.com/new — create a new repository called `booked-authority`, Public, no README, no .gitignore, no licence.
2. On the new empty repository page, click "uploading an existing file". Upload `index.html` and `vercel.json` from this package. Click "Commit changes".
3. Go to https://vercel.com/ebooks14 — make sure team "Ebooks" is selected at the top left.
4. Click "Add New" then "Project". Click "Import" next to the `booked-authority` repository. If GitHub asks, allow Vercel access to that repository only.
5. On the "Configure Project" screen, leave everything as it is. Framework Preset should say "Other". Do not add a build command, output directory, or environment variables. Click "Deploy".
6. Wait for "Congratulations". Vercel gives you a live URL like `booked-authority.vercel.app`. That is your public link to share.

## After it is live

- Check it on your phone with dark mode on. The page is light only, all 12 covers should show, and the Whom We Work With strip should move right to left.
- To change the page later, edit `index.html` in GitHub, commit, and Vercel redeploys automatically.
- Custom domain, when ready: in Vercel, open the project, Settings, Domains, and add your domain. Booked Authority domain is still being checked by the owner.
